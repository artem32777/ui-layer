# Файлы стилей проекта
## Директории:
- Глобальные стили проекта задаются в `./config/styles`.
- Миксины находятся в `./common/mixins`
- `./config/styles/shared` - файлы вложенной папки shared добавляются в конфиге в preprocessorOptions для того, чтобы использовать без импортов в компонентах.


## Главные файлы:
- `index.scss` - входная точка и глобальные стили селекторов.
- `null.scss` - обнуляющие стили селекторов.
- `colors.scss` - локальные значения css-переменных цветов проекта.
- `fonts.scss` - подключение шрифтов.
- `breakpoints.scss` - переменные брейкпоинтов проекта. (используется также для сторибука и миксина шрифтов).
- `typography.scss` - кастомные размеры шрифтов.
- `z-index.scss` - порядок индексов, который используется для fixed элементов.
- `transitions.scss` - глобальные стили для `<Transtion>` и `@keyframes`.
