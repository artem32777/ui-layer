# UI-слой содержит:

## Стили
- Глобальные стили проекта.
- Локальные переменные цветов, брейкпоинтов и др.
- Переиспользуемые миксины.
- Подробнее смотри в <span style={{color: '#1ea7fd'}}>[документации стилей](?path=/docs/design-system-файлы-стилей--docs)</span>.

## Ui-кит
- В некоторых компонентах используются примитивы <a href="https://reka-ui.com/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Reka UI</a>.
- Для <span style={{color: '#1ea7fd'}}>[таблиц](?path=/docs/ui-datatable--docs)</span> используется <a href="https://tanstack.com/table/latest" style={{color: '#1ea7fd', textDecoration: 'underline'}}>TanStack Table</a>.
- Для <span style={{color: '#1ea7fd'}}>[каруселей](?path=/docs/ui-slider--docs)</span> используется <a href="https://swiperjs.com/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Swiper</a>.
- Для <span style={{color: '#1ea7fd'}}>[тоста](?path=/docs/ui-toast--docs)</span> используется  <a href="https://vue-sonner.vercel.app/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Vue Sonner</a>..

## Формы
- Логика форм реализована с помощью <a href="https://vee-validate.logaretm.com/v4/guide/overview/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Vee-validate</a>.
- Правила валидации сделаны на <a href="https://zod.dev/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Zod</a>.
- Подробнее смотри в <span style={{color: '#1ea7fd'}}>[документации форм](?path=/docs/form-form--docs)</span>.

## Иконки:
- Для локальных иконок используется модуль `modules/svg-icon`.
- <span style={{color: '#1ea7fd'}}>[Каталог локальных иконок](?path=/docs/design-system-иконки--docs)</span>. в сторибуке.
- Подробнее смотри в <span style={{color: '#1ea7fd'}}>[документации компонента иконок](?path=/docs/ui-icon--docs)</span>.

## Тесты:
- Тесты компонентов и сценариев на <a href="https://vitest.dev/guide/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Vitest</a>.
- Тесты доступности на <a href="https://storybook.js.org/addons/@storybook/addon-a11y" style={{color: '#1ea7fd', textDecoration: 'underline'}}>addon-a11y</a>.
- Визуальные регрессии на <a href="https://storybook.js.org/addons/storybook-addon-playwright" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Playwright</a>.
- Команды запуска и подробности смотри в <span style={{color: '#1ea7fd'}}>[документации «Использование»](?path=/docs/docs-использование--docs)</span>.

## Сторибук:
- Документация системы дизайна.
- Документация и стори состояний ui-компонентов.
- Возможность изменения цветов и стилей компонентов.

## Другое:
- Переключатель тем.
- Вспомогательные функции.
