# Использование UI-слоя

## Локальный запуск Storybook
```bash
npm run storybook
```
- Запускает Storybook в dev режиме на [http://localhost:6006](http://localhost:6006).
- Используйте эту команду для просмотра историй компонентов, проверки их состояний, разработки и тестирования UI в изоляции.
- После изменения кода компонентов или историй страница обновляется автоматически.

## Тестирование
После завершения работы с кодом ui-компонентов запустите тесты историй и визуальное сравнение:

### Тесты историй компонентов
```bash
npm run test:stories
```
- smoke/render тесты всех компонентов.
- interaction-тесты из `play()`.
- accessibility-проверки axe в Chromium.


### Визуальное тестирование
```bash
npm run test:visual
```
- При отличиях от прошлого эталона, результаты и изображения сравнения сохраняются в `.storybook/test-results`.
- Проверьте все изменения и если всё соответствует ожидаемому результату, то сохрание новые эталоны.

### Сохранение новых эталлонов скриншотов.
После потдверждения изменений, сохраните новые эталоны:
```bash
npm run test:visual:update
```


## Тестирование одного компонента:
Если вы не хотите ждать тестирования, можно использовать команды для запуска только одного:
```bash
npm run test:stories -- Button.stories.ts
```

```bash
npm run test:visual:story -- ui-button--base
```

```bash
npm run test:visual:story:update -- ui-button--base
```
Либо использовать визуальный интерфейс сторибука, там есть опции запуска тестов.
