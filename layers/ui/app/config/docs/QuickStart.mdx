# Установка UI-слоя

## Структура:
Скопируйте `vitest.config.ts` и папки `.storybook` и `layers/ui` в свой проект:
```text
project/
├──  vitest.config.ts
├── .storybook/
└── layers/
    └── ui/
         └── nuxt.config.ts
         └── app/
```
