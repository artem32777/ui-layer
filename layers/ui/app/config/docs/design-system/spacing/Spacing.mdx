# Адаптивные расстояния
- Переменные расстояний формируются в файле `layers/ui/app/config/styles/spacing.scss`.

## Использование
- Используйте CSS-переменные `var(--spacing-*)` для `padding`, `margin`, `gap` и других размеров.
- Значение переменной автоматически меняется на брейкпоинтах, поэтому дополнительные медиазапросы не нужны.

```scss
.card {
	gap: var(--spacing-blue);
	padding: var(--spacing-pink);
}
```
