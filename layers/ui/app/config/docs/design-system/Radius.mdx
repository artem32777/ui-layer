# Скругления
- Варианты скругления задаются в `config/styles/variables/radius.scss`.
- Переключатель вешает класс `radius-*` на элемент `html` во всём Storybook. По умолчанию используется `radius-3`.
- В компонентах используйте переменные `var(--UI-radius-L)`, `var(--UI-radius-M)` и остальные токены выбранного варианта.
