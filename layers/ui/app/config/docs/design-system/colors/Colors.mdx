# Цвета

- Все цвета светлой и тёмной тем задаются напрямую в `config/styles/colors.scss`.
- Названия описывают назначение цвета. Текст и иконки используют одни и те же переменные.
- Клик по цвету на превью ниже для изменения.
- Влияет на цвета только в сторибуке.

## Как выбирать переменную

| Назначение | Переменные |
| --- | --- |
| Фон страницы и фон карточки, меню или диалога | `--background`, `--surface` |
| Спокойный фон кнопок и полей, его наведение | `--surface-muted`, `--surface-muted-hover` |
| Наведение на пункт меню и фон группы вкладок | `--surface-hover`, `--surface-group` |
| Основной текст, наведение, второстепенный и малозаметный текст | `--text`, `--text-hover`, `--text-muted`, `--text-subtle` |
| Недоступный текст и иконки | `--text-disabled` |
| Основная кнопка или выбранный контрол | `--primary`, `--primary-hover`, `--on-primary` |
| Акцентная кнопка | `--accent`, `--accent-hover`, `--on-accent` |
| Акцентная ссылка | `--accent`, `--text-accent-hover` |
| Обычная, мягкая и недоступная граница; индикатор фокуса | `--border`, `--border-muted`, `--border-disabled`, `--focus` |
| Невыбранный контрол, наведение и его ползунок | `--control`, `--control-hover`, `--control-thumb` |
| Полоса прокрутки и её наведение | `--scrollbar`, `--scrollbar-hover` |
| Фон активного поля | `--field-focus-background` |
| Кнопка поверх изображения | `--media-button`, `--media-button-hover`, `--on-media-button` |
| Текст и иконки поверх изображения | `--text-on-media`, `--text-on-media-hover`, `--text-disabled-on-media` |
| Тёмный фон для демонстрации изображения или медиа-контрола | `--media-background` |
| Статусы и цвет тени | `--error`, `--success`, `--info`, `--warning`, `--shadow` |

`on-*` — цвет содержимого на соответствующем фоне. Например, на `--primary` используется `--on-primary` независимо от темы.

Переменные для медиа сохраняют одинаковые значения в обеих темах. Для обычной кнопки используйте `--on-primary`, а не фиксированный светлый `--text-on-media`.

Фон страницы и поверхность, как и акцент и ошибка, остаются отдельными ролями даже при совпадающих значениях. Это позволяет менять их независимо.
