# Цвета
- Семантические цвета задаются напрямую в `config/styles/colors.scss`: светлая тема в `:root`, тёмная — в `.theme-dark`.
- Базовой палитры и промежуточных ссылок между цветовыми переменными нет.
- В стилях указываем цвета через эти переменные: `background-color: var(--primary);`.
- Для содержимого на основном фоне используем `color: var(--on-primary);`. Текст и иконки используют общие токены, состояния имеют суффиксы `-hover` и `-disabled`.
- Роли и правила выбора переменных описаны в [Цветах](?path=/docs/система-дизайна-цвета--docs).

# Темы
- Доступны светлая, тёмная и системная темы. Системная следует настройке `prefers-color-scheme`.
- Темы определяются в `config/theme.ts` и храняются в куки.
- Переключаются глобально для всего сайта с установкой класса на элемент `html`.
- Название темы также может быть передано в prop `theme` для стилизации определенного ui-компонента.
- Клиент может переключать темы с помощью компонента <span style={{color: '#1ea7fd'}}>[ThemeSwitcher](?path=/docs/ui-themeswitcher--docs)</span>.
