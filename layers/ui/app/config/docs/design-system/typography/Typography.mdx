# Типографика
- <span style={{color: '#1ea7fd'}}>[Подробнее про использование шрифтов в коде](?path=/docs/docs-шрифты--docs)</span>.

## Кастомные размеры шрифтов
- Кликните по пресету, чтобы изменить размер шрифтов, толщину, высоту строки и letter spacing.
- Изменения применяются ко всем компонентам в Storybook, использующим этот пресет.
- Кнопка "Сбросить всё", чтобы вернуть изначальные локальные настройки.

## Шрифт
- Файл `.woff2`, `.woff` или `.ttf` можно загрузить для предпросмотра и применить ко всем пресетам либо только к открытому пресету.
