# Типографика
## Использование
- Для кастомного размера шрифта используем миксин `font-size($name)`.
- Локальные настройки стилей кастомных размеров шрифтов находятся в `config/styles/shared/typography.scss`.
- Миксин генерирует значения свойств:`var(--font-h1-size-1, 116px)`, `var(--font-h1-weight, 600)` и т.д.
- Значения устанавливаются в фоллбэк, а переменные `--font` можно создавать и переопределять в сторибуке или с бэкенда.

## Пример

```scss
.section__title {
	@include font-size(h2);
}
```

## Демонстрация
- Кликните по пресету ниже, чтобы изменить размеры на брейкпоинтах, толщину, высоту строки и letter spacing. Изменения применяются ко всем компонентам в Storybook, использующим этот пресет.
- Файл `.woff2`, `.woff` или `.ttf` можно загрузить для предпросмотра и применить ко всем пресетам либо только к открытому пресету.
