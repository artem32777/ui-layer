# Popover
- Основан на <font color="blue">[`Popover из Reka UI`](https://reka-ui.com/docs/components/popover)</font>.
- Служит для показа дополнительного контента, отличающегося от меню, для меню есть компонент `DropdownMenu`.
- Если нужно показать простую подсказку, семантически правильнее использовать компонент `Tooltip`.
