# DateRangePicker

Поле для ввода и выбора диапазона дат из календаря. Основано на [`Date Range Picker` из Reka UI](https://reka-ui.com/docs/components/date-range-picker) и сохраняет встроенную клавиатурную навигацию.

## Использование

- `v-model` содержит `DateRange` с полями `start` и `end`.
- `v-model:open` позволяет управлять открытием панели календаря.
- `maximumDays` ограничивает длину диапазона, а `fixedDate` фиксирует его начало или конец.
- `minValue`, `maxValue`, `isDateDisabled`, `isDateUnavailable` и `isDateHighlightable` управляют доступностью дат.
- По клику на заголовок календаря открывается выбор месяца без изменения размера панели.
