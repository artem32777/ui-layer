# DatePicker

Поле для ввода и выбора одной даты из календаря. Основано на [`Date Picker` из Reka UI](https://reka-ui.com/docs/components/date-picker) и поддерживает ввод с клавиатуры по отдельным сегментам даты.

## Использование

- `v-model` содержит выбранное значение `DateValue`.
- `v-model:open` позволяет управлять открытием панели календаря.
- `v-model:placeholder` управляет месяцем, отображаемым в календаре.
- `minValue`, `maxValue`, `isDateDisabled` и `isDateUnavailable` ограничивают доступные даты.
- По клику на заголовок календаря открывается выбор месяца без изменения размера панели.
