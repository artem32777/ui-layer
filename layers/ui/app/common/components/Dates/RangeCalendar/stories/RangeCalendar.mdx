# RangeCalendar

Календарь для выбора непрерывного диапазона дат. Основан на [`Range Calendar` из Reka UI](https://reka-ui.com/docs/components/range-calendar) и использует общие стили с `Calendar`.

## Когда использовать

- `v-model` содержит `DateRange` с полями `start` и `end`.
- `minValue` и `maxValue` ограничивают доступный диапазон дат.
- `maximumDays` задаёт максимальную длину диапазона.
- `fixedDate` фиксирует начало или конец диапазона.
- `allowNonContiguousRanges` разрешает включать в диапазон недоступные даты.
- `isDateDisabled`, `isDateUnavailable` и `isDateHighlightable` управляют доступностью и подсветкой дат.
- `numberOfMonths` задаёт количество одновременно отображаемых месяцев.
