# RangeSlider

Ползунок для выбора одного значения, диапазона или нескольких непересекающихся диапазонов.

## Когда использовать

- `type="double"` — интервал между двумя значениями.
- `type="one-range"` — одно значение.
- `variant="block"` — компактное блочное отображение значений.
- `MultiRangeSlider` — несколько интервалов на одной шкале; значения передаются парами.
