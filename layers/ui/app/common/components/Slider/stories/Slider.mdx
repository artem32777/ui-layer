# Slider
- Основан на <font color="blue">[`Slider из Reka UI`](https://reka-ui.com/docs/components/slider)</font>.
- Варианты: `two-points` (диапазон) и `one-point` (одно значение). Размеры: `medium`, `big`.
- `MultiSlider` — несколько непересекающихся интервалов на одной шкале; значения передаются парами.
- Лейбл, подсказка и ошибка — через `FormSlider` (`FormFieldProps`: `name`, `label`, `hint`).

## FormSlider

Адаптер `Slider` для `vee-validate`: значение, ошибка и лейбл по имени поля (`FormFieldProps`: `name`, `label`, `hint`).

Ошибка появляется после ухода с поля: `validateOnValueUpdate` выключен, валидация на blur. Чтобы скрыть ошибку, нужно исправить значение и снова уйти с поля.
