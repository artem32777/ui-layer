Визуальный или семантический разделитель между связанными группами контента. Основан на `Separator` из Reka UI.

## Когда использовать

- Чтобы визуально разделить блоки контента или элементы панели управления.
- `orientation="horizontal"` — между блоками, расположенными друг под другом.
- `orientation="vertical"` — между элементами в горизонтальном ряду.
- `decorative=true` — когда разделитель нужен только для оформления.
- `decorative=false` — когда разделение должно быть доступно вспомогательным технологиям.
