# Tabs
- Основан на <font color="blue">[`Tabs из Reka UI`](https://reka-ui.com/docs/components/tabs)</font>.
- Варианты: `button` (сегментированные) и `text` (подчёркивание). Размеры: `medium`, `big`.
- У элемента `items` можно передать `iconLeft`, `iconRight` или `icon` (только иконка).

## Слоты
Имена слотов = `value` из `items`. Для `{ value: 'account', label: 'Account' }` контент передаётся в `#account`.
