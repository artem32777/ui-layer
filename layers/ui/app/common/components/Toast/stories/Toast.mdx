# Toast

Временное уведомление о результате действия. Отображается в правом нижнем углу.

## Когда использовать

- Слот `trigger` передаёт функцию `showToast` для запуска уведомления.
- Toast подходит для подтверждения завершённого действия, не требующего немедленного ответа.
- В уведомлении доступно действие отмены.
