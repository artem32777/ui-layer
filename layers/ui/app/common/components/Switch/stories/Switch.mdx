# Switch

Компонент переключателя. Используется для бинарных настроек, когда изменение можно применить сразу без отдельной кнопки сохранения.

## Когда использовать

- `v-model` — управляет состоянием переключателя.
- `disabled` — отключает переключатель и запрещает изменение значения.

## Базовый пример

<Canvas of={SwitchStories.Unchecked} />

<Controls of={SwitchStories.Unchecked} />

## Варианты

### Включён

```vue
<Switch v-model="isEnabled" />
```

### Отключённое состояние

```vue
<Switch
	v-model="isEnabled"
	disabled
/>
```
