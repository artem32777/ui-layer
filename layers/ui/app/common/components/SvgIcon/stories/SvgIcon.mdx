# SvgIcon

Компонент выводит SVG-иконку из локального типизированного реестра. Имя передаётся через объект `iconNames`, чтобы сохранить автодополнение и проверку типов.

## Когда использовать

- Для всех интерфейсных иконок из `layers/ui/app/modules/svg-icon/icon-source`.
- Числовой `size` задаёт одинаковую ширину и высоту в пикселях.
- Строковый `size` позволяет использовать CSS-единицы, например `1.5rem`.
- `color` задаёт цвет явно; без него иконка наследует `currentColor` родителя.

Не передавайте имя произвольной строкой и не вставляйте inline-SVG или символы вместо существующей системной иконки.
