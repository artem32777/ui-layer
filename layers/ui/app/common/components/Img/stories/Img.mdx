# Img
- Компонент для вывода простых изображений.
- Задаёт `loading=lazy` и стили `width: 100%`, `height: 100%`, `object-fit: cover`.
- Используется как fallback внутри компонента `Picture`.
- Для LCP-изображений не забудь установить `loading`, `fetchPriority`.
