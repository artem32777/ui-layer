# OverflowNavigation

Компонент распределяет пункты навигации между видимой областью и меню переполнения в зависимости от ширины контейнера.

## Когда использовать

- Для горизонтальной навигации, которая должна помещаться в контейнер без переноса строк.
- `overflowWidth` должен соответствовать ширине кнопки или другого элемента, открывающего скрытые пункты.
- Слот самостоятельно определяет разметку видимых пунктов и меню переполнения.

Default-слот должен возвращать один корневой список: компонент клонирует его непосредственных дочерних элементов в скрытый список для измерения. Значение `overflowWidth` должно включать полную ширину элемента, открывающего скрытые пункты.

## Базовый пример

Потяните правую границу контейнера, чтобы увидеть изменение `visibleItems`, `overflowItems` и `hasOverflow`.
