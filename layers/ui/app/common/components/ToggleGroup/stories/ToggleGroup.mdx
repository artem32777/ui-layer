# ToggleGroup

Группа связанных переключателей для выбора одного или нескольких значений.

## Когда использовать

- `type="single"` — выбор одного значения.
- `type="multiple"` — независимый выбор нескольких значений.
- `options` содержит подпись, значение и необязательное состояние `disabled`.
