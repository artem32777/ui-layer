# Textarea

Многострочное текстовое поле для длинных сообщений, описаний и комментариев. Поддерживает `v-model`, количество строк, disabled-состояние и invalid через `aria-invalid`.

## Когда использовать

- `rows` — чтобы задать стартовую высоту поля.
- `disabled` — если редактирование временно недоступно.
- `aria-invalid="true"` — если поле связано с ошибкой валидации.
