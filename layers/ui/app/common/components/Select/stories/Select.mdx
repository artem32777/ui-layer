# Select

- Выпадающий список основан на [`DropdownMenu`](?path=/docs/ui-dropdownmenu--docs);
- `v-model` имеет тип `string`, при `multiple` — `string[]`.
- Пока ничего не выбрано, в поле показывается `placeholder`. При множественном выборе меню остаётся открытым после клика по пункту.
- Ширина выпадающего меню всегда равна ширине триггера.

## FormSelect

Адаптер `Select` для `vee-validate`: значение, ошибка и лейбл по имени поля (`FormFieldProps`: `name`, `label`, `hint`).

Ошибка появляется после закрытия меню или ухода с поля: `validateOnValueUpdate` выключен, валидация на close/blur. Чтобы скрыть ошибку, нужно выбрать значение (или исправить и снова закрыть меню).
