## Пример использования

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { iconNames } from '#layers/ui/app/modules/svg-icon'
import Input from '#layers/ui/app/common/components/Input/Input.vue'

const value = ref('')
</script>

<template>
	<Input
		v-model="value"
		:icon="iconNames['search-md']"
		placeholder="Введите запрос"
		aria-label="Поиск"
	/>
</template>
```

## FormInput

Адаптер `Input` для `vee-validate`: значение, ошибка и лейбл по имени поля (`FormFieldProps`: `name`, `label`).

Ошибка появляется после ухода с поля: `validateOnValueUpdate` выключен, валидация на blur. Чтобы скрыть ошибку, нужно исправить значение и снова уйти с поля.
