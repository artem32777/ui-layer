# Spinner
- Круговой индикатор неопределённого времени загрузки.
- Цвет наследуется от контекста через `currentColor`, по умолчанию используется цвет `var(--brand)`.
- Компонент имеет роль `status`.
- Через `label` можно уточнить доступное название состояния загрузки.
- При включённой системной настройке `prefers-reduced-motion` вращение отключается.

## Размеры

Доступны размеры `s` (16 px), `m` (24 px) и `l` (32 px).
