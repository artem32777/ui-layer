# Правила кнопок, форм и модалок

Эта страница фиксирует базовые правила использования интерактивных компонентов. Детальные props и состояния остаются в документации конкретных компонентов.

## Кнопки

<Canvas of={DesignSystemStories.ButtonsRules}/>

- `base` используем для главного действия в контексте.
- `outline` используем для вторичного действия рядом с главным.
- `ghost` используем для спокойных действий в плотном интерфейсе.
- Иконку передаём через `iconNames`, для icon-only кнопки обязательно задаём `aria-label`.
- Состояния `hovered`, `focused`, `pressed`, `disabled`, `progress` полезны в историях и визуальных проверках.

## Формы

<Canvas of={DesignSystemStories.FormsRules}/>

- У поля всегда должен быть понятный label рядом с контролом.
- Ошибку показываем рядом с полем и окрашиваем через `var(--red)`.
- `aria-invalid="true"` используем для invalid-состояния нативных полей.
- Disabled-состояние не должно выглядеть как ошибка.

## Модалки

<Canvas of={DesignSystemStories.ModalRules}/>

- Заголовок объясняет объект действия.
- Description коротко объясняет последствия или контекст.
- Основное действие ставим последним в группе действий.
- Закрытие должно быть доступно через стандартный close-контрол и клавиатуру.
