# Ui-layer
Слой Nuxt-приложения https://nuxt.com/docs/4.x/getting-started/layers

## Фичи:
- Самописный UI-кит
- Компонеты форм и валидация
- Модуль генерации типизированных иконок
- Дополнительные утилиты типа переключателя тем
- Витрина компонентов storybook
- 100% покрытие визуальными и юнит-тестами
- Правила для агентов

## Структура:
```text
project/
├── .storybook/
└── layers/
    └── ui/
         └── nuxt.config.ts
         └── app/  - Внутри app используется модульная структура директорий.
```

## Ui-кит:
- В некоторых компонентах используются примитивы headless библиотеки <a href="https://reka-ui.com/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Reka UI</a>.
- Для таблиц - <a href="https://tanstack.com/table/latest" style={{color: '#1ea7fd', textDecoration: 'underline'}}>TanStack Table</a>.
- Для каруселей - <a href="https://swiperjs.com/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Swiper</a>.
- Для тоста -  <a href="https://vue-sonner.vercel.app/" style={{color: '#1ea7fd', textDecoration: 'underline'}}>Vue Sonner</a>


## Формы и валидация
- Логика форм сделана с помощью Vee-validate.
- Валидация с Zod.
- Компоненты расположены в `layers/ui/app/modules/form`.
- Отдельная группа в стори http://localhost:6006/?path=/docs/form-form--docs.

## Иконки:
- Используйте компонент `Icon` и модуль автоматической генерации иконок из svg-файлов - `app/modules/svg-icon`.
