# Сетка

Сетка и брейкпоинты лежат в `app/config/styles/shared/grid.scss` и `app/config/styles/shared/breakpoints.scss`. Базовая сетка состоит из 36 колонок.

<Canvas of={DesignSystemStories.GridBreakpoints} />

## Правила

- В медиа-запросах используем только проектные брейкпоинты: `$xxxs`, `$xxs`, `$xs`, `$sm`, `$md`, `$lg`, `$xl`, `$xxl`, `$xxxl`.
- Медиа-запросы пишем внутри класса компонента.
- Для ширин от сетки используем `column($number, $of)` или миксины `padding-x` / `margin-x`.
- Не привязываем UI-компоненты к сетке страницы, если компонент должен быть переиспользуемым.

## Пример

```scss
.layout {
	display: grid;
	grid-template-columns: repeat(36, 1fr);
	gap: 16px;

	@media (max-width: $sm) {
		grid-template-columns: repeat(12, 1fr);
	}
}

.layout__content {
	grid-column: span 24;

	@media (max-width: $sm) {
		grid-column: span 12;
	}
}
```
