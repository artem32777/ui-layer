# Иконки

Иконки используются через `Icon` и типизированный реестр `IconName`. Имена берём из `iconNames`, а не передаём строками вручную.

<Canvas of={DesignSystemStories.IconsGallery} />

## Правила

- Импортируем `Icon` из `#layers/ui/app/modules/svg-icon/components/SvgIcon.vue`.
- Импортируем `iconNames` из `#layers/ui/app/modules/svg-icon/runtime/iconNames`.
- В компонентах передаём имя так: `:name="iconNames.plus"`.
- Не используем символы, inline-SVG или произвольные строки, если иконка должна жить в системе.
- Если подходящей иконки нет, сначала добавляем SVG в исходный каталог и регенерируем реестр.
