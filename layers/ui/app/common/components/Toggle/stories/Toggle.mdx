# Toggle

Кнопка с двумя состояниями для включения и выключения отдельной настройки.

## Когда использовать

- `v-model` хранит нажатое состояние.
- `variant="outline"` добавляет рамку.
- `size` поддерживает значения `sm` и `lg`.
- Для кнопки без текстовой подписи задавайте `aria-label`.
