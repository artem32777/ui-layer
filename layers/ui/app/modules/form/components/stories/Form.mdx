# Form

Адаптеры компонентов дизайн-системы для `vee-validate`. Они связывают значение, состояние ошибки и сообщение валидации по имени поля.

Ошибка поля появляется после ухода с него: `validateOnModelUpdate` выключен, `validateOnBlur` включён. При следующем вводе ошибка сразу скрывается и снова показывается только после следующего ухода с поля.
